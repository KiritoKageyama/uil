recommended **publishing** instead, a decision matrix, a filing order, an
explicit *not novel — don't claim* list, and a *grey zone* list needing stronger
evidence. The headings survive; the reasoning behind each call does not.

Note that several claims it was built on have since been overturned — see the
2026-08-12 addendum in `CLAUDE.md` (four corrections table). Any rewrite should
start from current measurements, not from reconstructing this file.
