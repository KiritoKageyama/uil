Where it honestly wins

On saturated tabular data the cognitive layer ties plain XGBoost+PSO on accuracy. Its defensible value: the symbolic / extrapolation domain (symbolic regression categorically beats XGBoost out-of-range) and inspectable, replayable, human-editable knowledge — every model is a readable law, not a black box.

How to use this console
  1. Mission Control — pick a dataset and classifier (SymbolicFormula is the default and the recommended one), set stages, and start a run. Live charts, the stage-by-stage decision trace, and memory counters stream in over WebSocket.
  2. Knowledge Graph — watch the belief network the system builds: principles as nodes, leads_to / contradicts / depends_on edges. Switch to the mindmap for a hierarchical view. Click any node to edit its confidence or tier.
  3. Formulas / Principles — inspect the evolved loss formulas and symbolic classifiers, the mined principles and their confidence, and the causal hypotheses with their experimental status.
  1. Memory Proof — verify learning persists: on-disk stores grow across runs, champions resume accuracy, and everything pruned lands in the archive (nothing is lost).
  2. Human in the Loop — review knowledge cells between runs: accept, edit, or reject any belief. Every action becomes a human_edit / human_reject event you can undo by replay.
  3. Goal Director & Timeline — set a top-down goal the next run must honor, and scrub through the event-sourced history of everything the system has ever believed.

Sneak peek — how human-in-the-loop actually works
1
The system learns

Every run mines principles, grows the knowledge graph, evolves formulas, and tests causal hypotheses. Each belief is a knowledge cell — the smallest self-modifiable unit.

2
Everything is an event

Every change is appended to the VersionStore — an event-sourced, lossless history. Nothing is ever silently overwritten; state at any past moment can be reconstructed byte-identically.

3
You review between runs

Below, every cell the system believes is listed with its human-readable form and confidence. You are the peer reviewer of a machine scientist.

4
Edit or reject

Change a confidence, demote a tier, or reject a belief outright. Your action is recorded as a human_edit / human_reject event and applied to the materialized store — both paths, so it survives snapshots (bug #16's hard-won invariant).

5
Undo is replay

Made a mistake? Reconstruct the state at any earlier sequence number — the Replay panel below previews exactly what the system believed before your change.

6
The next run honors you

Edited confidences steer principle selection; rejected cells stay dead; goals set in the Goal Director bias attention. Verified end-to-end: a human edit survives the event stream, replay, and a fresh snapshot.
