    05 · HUMAN LOOP

    How the human loop works.

    Six steps from machine belief to human correction — and back.

    1It learns

    Each run mines principles, grows the graph, evolves formulas, tests causal hypotheses. Each belief is a knowledge cell.

    2Everything is an event

    Every change is appended to a lossless VersionStore. Nothing is silently overwritten.

    3You review

    Every cell is listed with a human-readable form and confidence. You are the peer reviewer.

    4Edit or reject

    Change a confidence, demote a tier, or reject a belief. Recorded to the store and the event stream.

    5Undo is replay

    Reconstruct the state at any earlier sequence — the console previews exactly what changed.

    6The next run honors you

    Edited confidences steer selection; rejected cells stay dead; goals bias attention.

    07 · HONESTY

    What UIL honestly is.

    On saturated tabular data, the cognitive layer ties plain XGBoost + PSO on accuracy — at more compute. We don't pitch a raw-accuracy miracle, because measured across seeds it isn't one.

    Its real, defensible value is two things: the symbolic / extrapolation domain, where symbolic regression categorically beats gradient boosting out-of-range; and inspectable, replayable, human-editable knowledge — a model that is a readable law and a lab notebook you can correct, not a weight blob.

    — measured multi-benchmark, held-out, cross-seed. Numbers you can reproduce with experiments/eval_crossseed.py.
